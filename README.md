# LRUTabs

ブラウザのタブをLRU方式で自動的に管理する Chrome 拡張です。開いているタブが一定数を超えると、古いタブを閉じて後から再度開けるよう保存しておきます。

## 開発環境の準備

1. Node.js と [pnpm](https://pnpm.io/) をインストールしてください。
2. 依存関係をインストールします。
   ```bash
   pnpm install
   ```
3. 開発用ビルドを起動します。
   ```bash
   pnpm start
   ```
   `dist/` 以下に生成されるファイルを Chrome の「拡張機能」ページから読み込むと開発中の拡張を確認できます。
4. 配布用ビルドを作成する場合は次を実行します。
   ```bash
   pnpm build
   ```
   生成された `dist/` フォルダーをそのまま Chrome に読み込んでください。
